# Coding-Through-Minecraft
A free educational initiative using Minecraft mods to teach systems thinking, automation, logic, and programming through hands-on projects.

Currently there are 3 courses planned for development for this ecosystem:

Learn To Code With IntegratedDynamics is an introductory 7-week course to systems and logical thinking, using a Minecraft mod IntegratedDynamics to introduce constructs of logic like cause-and-effect, eventually moving to Javascript in the last two weeks. This course is intended for ages 10-14

Digital Logic through ProjectRed uses the ProjectRed mod to create a more traditional logic course. Students learn to build circuits and truth tables, as well as solve unique automation challenges. This is currently marked as a future project, as of now it is just an idea. This course is recommended to ages 12-14.

Lua through OpenComputers is the last course in this ecosystem, focusing on using OpenComputers to create Lua scripts to control the world of Minecraft, and can serve as a formal introduction to Lua, an important scripting language. This course is recommended for ages 12-14. This course is also a future project because I have something known as a "life". Crazy, I know.
